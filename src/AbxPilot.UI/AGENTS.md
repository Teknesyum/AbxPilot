# AbxPilot.UI

Avalonia shared UI: App, MainWindow, MainView, view models, theme, title bar.

- Colours, durations, sizes only from `Themes/Palette/Neon/Theme.axaml` (generated by teknesyum-ui setup).
- `Themes/Theme.axaml`: icons and app-only sizes. `Themes/Controls.axaml`: control themes.
- Custom title bar: `WindowDecorations="BorderOnly"`, BeginMoveDrag, double-click toggles maximize.
- Visible text only via `{loc:Text key}`; keys in `kb/i18n/tr.json` and `en.json`, sentence case.
- No Watermark, no visual theme library, no comments in code.
- Reduced motion: the `anim` class is added to the window only when motion is allowed.
